# Standards

The standards live in [standards.md](standards.md). This page is a pointer. It is not a copy.

Application documentation links here. Do not restate a standard in an application document. Link to this page.

d-LitFunc is Diátaxis + Literal + Functional. Document shape follows [Diátaxis](https://diataxis.fr). Requirement words follow [RFC 2119](https://www.rfc-editor.org/rfc/rfc2119).

A reader can read the documentation as a story. The four kinds interconnect. A deeper dive is a link. The destination links back so the reader can continue with a deeper understanding.

A code comment that addresses a function links to [standards.md](standards.md) or to the specific section of a document that addresses that function.

The source of truth is the d-LitFunc repository. The remote can be any forge. The links are relative.
